Millénaire 行为目标 (Villager Goal) 调拨分析回执
一、 行为目标详细解析
1. millenaire:bring_back_home（身上物品回家归仓）
* 物流方向：村民个人背包 (VillagerInventory) $\rightarrow$ 居住建筑箱子 (Home BuildingInventory)
* 关联 JSON 字段：
  * 村民职业 JSON（如 wife.json）：
    * goals: 声明 "millenaire:bring_back_home" 注册项。
    * bring_back_home_goods: 数组类型（如 ["minecraft:dirt", "minecraft:wood"]），显式指定哪些物品采集/产出后必须存回自己家。
* 源码解释 (基于 BringBackHomeGoal.java)：
  * 启动判定 (canStart)：通过 ModCultures.getVillagerType() 校验村民职业是否有配置 bringBackHomeGoods()，且村民拥有合法 homeBuilding。
  * 动态优先级计算 (computePriority)：
    $$\text{Priority} = 10 + (\text{nbGoods} \times 3)$$
    身上符合归仓条件的物品数量越多，目标优先级越高，确保村民在外采资源后优先回屋清包。
  * 执行逻辑 (BringBackHomeTask)：
    1. 寻路至 home.getPathStartPos()。
    2. 遍历 villagerInv，调用 BringBackHomeGoal.isBringBackGood() 过滤目标物品。
    3. 调用 buildingInv.add() 存入家箱子，成功转移后扣除背包数量；若家箱子全满无法存入，触发 throttle.recordFailedTransfer() 记录失败频控，防止频繁无效寻路。
2. millenaire:deliver_resources_shop（工坊产物上交市政厅/总仓）
* 物流方向：居住建筑/工坊箱子 (Home/Workshop Inventory) $\rightarrow$ 市政厅箱子 (Townhall Inventory)
* 关联 JSON 字段：
  * 村民职业 JSON：在 goals 中配置 "millenaire:deliver_resources_shop"。
  * 建筑 JSON（如 maid_mechanical_workshop.json）：
    * collect_goods: 显式白名单（若配置，仅上交指定物品）。
    * deliver_to: 指定送货的目标建筑标签（默认送往 townhall）。
* 源码解释：
  * 逻辑定位：负责村庄物流的前半段（产出送库）。
  * 过滤机制：扫描当前工坊箱子中的物品。若 JSON 配置了 collect_goods，则严格进行白名单比对；若未配置，则调用 townhall.getNbGoodNeeded(item) 进行动态需求匹配。只要市政厅建材施工计划、交易或生产链需要该物品，即触发搬运任务。
3. millenaire:get_resources_for_shops（店铺/售货摊位补货）
* 物流方向：市政厅 / 居住建筑 (Townhall / Home) $\rightarrow$ 商业建筑/售货摊位 (Shop / Market Stall)
* 关联 JSON 字段：
  * 村民职业 JSON：在 goals 中配置 "millenaire:get_resources_for_shops"（通常配给商人、妻子等负责贩售的角色）。
  * 建筑 JSON：
    * shop: 声明该建筑为商店类型。
    * sells / buys: 声明商店经营的物品清单。
* 源码解释：
  * 逻辑定位：负责村庄物流的后半段（调拨到售货端）。
  * 源码限制：核心方法 computePickupRequests 仅向 checkSource(home, ...) 与 checkSource(townhall, ...) 发起检索。它只认可市政厅或家里现成的库存，一旦商店需要补充待售商品，村民会从市政厅提取并转运至商店货架箱。
4. millenaire:get_goods_for_household（家庭生活物资采买）
* 物流方向：市政厅 / 市场 (Townhall / Shop) $\rightarrow$ 居住建筑箱子 (Home Inventory)
* 关联 JSON 字段：
  * 村民职业 JSON：在 goals 中配置 "millenaire:get_goods_for_household"。
  * 文化/职业 JSON：
    * household_goods: 声明家庭维护所必需的生活物资列表（如面包 craft_bread、苹果酒 cider、燃料、茅草等）。
* 源码解释：
  * 逻辑定位：后勤维持与家庭生存消耗逻辑。
  * 判定机制：系统定期检查村民 HomeBuilding 的库存。当检测到基础食物、饮品或生活用品储备低于设定阈值时，目标触发。村民前往市政厅或市场采购物资并搬回家中存放，供家庭成员日常消耗。
